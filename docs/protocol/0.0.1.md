# Stream protocol 0.0.1

- **Version:** `0.0.1`
- **Status:** Superseded by [0.0.2](./0.0.2.md)
- **Since:** initial release
- **Compatibility:** a strict subset of 0.0.2 (0.0.2 decoders still accept it)

## Wire format

Apache Arrow IPC streaming format (one schema message + N record-batch messages).
The protocol version is carried in schema-level metadata:
`trd.protocol.version = "0.0.1"`. **1 row = 1 frame**; the output is 1:1 with the
input.

## Input schema

| Column | Arrow type | Meaning |
|---|---|---|
| `center` | `FixedSizeList<Float32>[2]` | Triangle centroid in NDC; `(0,0)` is screen center. |
| `size` | `FixedSizeList<Float32>[2]` | Per-axis scale; `(1,1)` is the base triangle. |
| `theta` | `Float32` | Rotation in radians, counter-clockwise. |

All columns are **non-nullable** (including the fixed-size-list children).

## Output schema

| Column | Arrow type | Meaning |
|---|---|---|
| `r`, `g`, `b`, `a` | `FixedSizeList<UInt8>[width*height]` as `arrow.fixed_shape_tensor` of shape `[height, width]` | One channel plane per rendered image. |

One output row per input frame.

## Semantics & conventions

Each base triangle vertex `p_i` is transformed as
`p' = center + R(theta) · (size ⊙ p_i)`, authored directly in NDC (clip space),
`z = 0`.

## Example (input)

A two-frame stream: the identity triangle, then a half-size triangle rotated by
`1.0` rad and shifted.

| center | size | theta |
|---|---|---|
| `[0, 0]` | `[1, 1]` | `0.0` |
| `[0.1, -0.2]` | `[0.5, 0.5]` | `1.0` |
