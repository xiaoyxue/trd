# Stream protocol 0.0.6

- **Version:** `0.0.6`
- **Status:** current and the only accepted input version
- **Compatibility:** none; every other or missing version is rejected

The input is a sequence of concatenated Apache Arrow IPC streams. Resource
tables precede the terminal per-render-frame params table:

```text
[mesh] [texture?] [frames?] [params]
```

There is no mesh-less input fallback. Standalone params decoding exists only as
an internal authoring helper for front-ends that already own their meshes.

## Required schema metadata

Every input sub-stream schema carries:

| Key | Value |
|---|---|
| `trd.protocol.version` | exactly `0.0.6` |
| `trd.table.kind` | `mesh`, `texture`, `frames`, or `params` |

Explicit kinds replace column-name sniffing and make the optional frames tensor
unambiguous from the albedo texture table. Missing keys, unknown kinds, duplicate
resource tables, and out-of-order tables are hard errors.

The params schema may also carry `trd.stream.frame_rate` (positive float frames
per second, default `30`). Front-ends use it as playback speed and the headless
renderer copies it to the output image stream.

## Global conventions

- Matrices are column-major and right-handed.
- Projection targets wgpu clip space (`z in [0, 1]`).
- The vertex chain is `clip = P * V * M * (position, 1)`.
- Image pixels have a top-left origin and sRGB byte values.

## Mesh table

One row is one mesh; params draw IDs use the 0-based row ordinal.

| Column | Arrow type | Required | Meaning |
|---|---|:---:|---|
| `position` | `List<FixedSizeList<Float32>[3]>` | yes | Vertex positions. |
| `color` | `List<FixedSizeList<Float32>[3]>` | no | Vertex RGB; absent means white. |
| `uv` | `List<FixedSizeList<Float32>[2]>` | no | Top-left-origin texture coordinates. |
| `index` | `List<UInt32>` | no | Triangle indices; absent means sequential. |

`scripts/obj_to_arrow.py` is the reference producer.

## Texture table (optional)

One row is the mesh albedo:

| Column | Arrow type | Meaning |
|---|---|---|
| `rgba` | `FixedSizeList<UInt8>[H*W*4]` with `arrow.fixed_shape_tensor` shape `[H,W,4]` | Row-major RGBA8 albedo. |

The first non-empty row is bound for textured/PBR draws.
`scripts/texture_to_arrow.py` is the reference producer.

## Frames table (optional)

One row is one inline background image resource. Its 0-based row ordinal is the
`frame_id` used by params; the table is not positionally zipped with params, so
several render frames may reuse one image.

| Column | Arrow type | Meaning |
|---|---|---|
| `frame_bytes` | nullable `Binary` | Encoded PNG or JPEG bytes. |
| `frame_pixels` | nullable `FixedSizeList<UInt8>` with `arrow.fixed_shape_tensor` shape `[H,W,C]` | Raw row-major pixels; `C` is 3 or 4. |

Each row has exactly one non-null payload. RGB tensors gain opaque alpha; RGBA
is preserved byte-for-byte. Because tensor shape is field metadata, all non-null
`frame_pixels` rows in one table share their dimensions and channel count.
Encoded bytes support varying dimensions.

Malformed metadata, wrong types, null tensor children, empty bytes, unsupported
formats, invalid dimensions, and wrong byte lengths are errors. Encoded rows
remain compressed until selected; raw rows occupy their full RGBA-sized memory.
The complete frames resource table is retained before params playback, so use:

- `frame_bytes` for bounded self-contained clips;
- `frame_pixels` for small fixtures or zero-codec producers;
- external `frame_path` / `frame_url` for large or unbounded video.

`scripts/frames_to_arrow.py` authors either inline form.

## Params table

One row is one rendered frame. Params is terminal.

| Column | Arrow type | Meaning |
|---|---|---|
| `model` | `FixedSizeList<Float32>[16]` | Single-object fallback model. |
| `k` | `FixedSizeList<Float32>[9]` | CV camera intrinsics. |
| `pose` | `FixedSizeList<Float32>[16]` | CV camera-to-world pose. |
| `eye`, `target`, `direction`, `up` | `FixedSizeList<Float32>[3]` | CG look-at camera vectors. |
| `fovy`, `aspect`, `znear`, `zfar` | `Float32` | CG perspective values. |
| `draw_mesh` | `List<UInt32>` | Mesh-table row IDs. |
| `draw_model` | `List<FixedSizeList<Float32>[16]>` | Per-draw models; length equals `draw_mesh`. |
| `draw_mode` | `List<UInt8>` | Optional per-draw mode; length equals `draw_mesh`. |
| `frame_path` | nullable `Utf8` | Native shell image reference. |
| `frame_url` | nullable `Utf8` | Browser shell image reference. |
| `frame_id` | nullable `UInt32` | Frames-table row ID. |

All columns are optional/additive. A stream without draw columns renders mesh 0
using `model`; explicit empty draw lists render no meshes. `draw_mode` values are
`0` filled, `1` wireframe, `2` textured, `3` shadow, `4` PBR, and `255` inherit.

CV camera (`k`/`pose`) and CG camera columns are mutually exclusive. CV uses
`view = inverse(pose)`; CG uses `eye` plus `target` or `direction`. Missing camera
data uses the default camera.

### Background source

A params row has at most one logical background source:

- inline: non-null `frame_id`;
- external: non-empty `frame_path` and/or `frame_url`.

`frame_id` requires a preceding frames table and must be in range. Inline and
external sources on one row conflict and are rejected. When both external
columns exist, `frame_path` is preferred per row and `frame_url` is its fallback.
Null/empty external references and null `frame_id` mean no background.

Inline images are decoded in `trd-core` and automatically uploaded by native and
wasm renderers. External references retain the shell boundary: native resolves a
path under `--frames-base`; browser JavaScript fetches the URL and uploads RGBA.

## Rendering and output

Every background is drawn as `DrawableObject::FramePlane`, a fullscreen triangle
drawn before meshes with depth writes disabled. The frame texture is separate
from mesh albedo, uses `Rgba8UnormSrgb`, linear sampling, clamp-to-edge, and a
reused allocation.

Output is one row per params row: planar `r`, `g`, `b`, and `a`
`fixed_shape_tensor<UInt8>[height,width]` channels. Params input batch boundaries
are mirrored on output.

## Examples

External reference:

```sh
{ scripts/obj_to_arrow.py bunny.obj
  scripts/jsonl_to_arrow.py frames-with-frame_path.jsonl
} | trd-cli --width 320 --height 180 --frames-base output/clip
```

Self-contained inline stream:

```sh
scripts/frames_to_arrow.py --storage bytes output/clip/frames/*.jpg \
  -o /tmp/frames.arrow

# JSONL rows use {"frame_id": 0}, {"frame_id": 1}, ...
{ scripts/obj_to_arrow.py bunny.obj
  cat /tmp/frames.arrow
  scripts/jsonl_to_arrow.py frames-with-frame_id.jsonl
} | trd-cli --width 320 --height 180
```

The accepted version is `crates/trd-core/src/protocol.rs::PROTOCOL_VERSION`.
Native and wasm use the same `InputSession` framing and column decoder.
