# Stream protocol 0.0.3

- **Version:** `0.0.3`
- **Status:** Current
- **Since:** this release
- **Compatibility:** backward-compatible with [0.0.2](./0.0.2.md) and
  [0.0.1](./0.0.1.md) — a params-only stream decodes and renders identically;
  decoders accept `{0.0.1, 0.0.2, 0.0.3}`.

## Wire format

Apache Arrow IPC streaming format. `0.0.3` introduces **multi-stream framing**: an
optional leading **mesh** IPC stream, **concatenated before** the params IPC
stream on the same input (two schema+batches sequences back-to-back):

```
[ mesh stream ]  [ params stream ]
```

Both are ordinary Arrow IPC streams (schema message + N record-batch messages +
end-of-stream). The reader consumes the first stream to its end-of-stream marker,
then reads the second from the same byte source. A **params-only** stream (no
leading mesh) is exactly a `0.0.1`/`0.0.2` stream and renders the built-in
hello-triangle — full backward compatibility.

The two streams are told apart by **schema sniffing**: a first stream whose schema
has a **`position`** column is a mesh table; otherwise the input is a legacy
params-only stream.

## Mesh stream schema

**One row = one mesh.** All rows are decoded (in order) into a mesh list that a
frame's [draw list](#params-stream-schema) references by 0-based index; a
single-mesh table is the common case. Geometry is nested in **list columns** so
per-vertex and per-index data of differing lengths coexist in a single record
batch:

| Column | Arrow type | Required | Meaning |
|---|---|:--:|---|
| `position` | `List<FixedSizeList<Float32>[3]>` | yes | Per-vertex positions `(x, y, z)`, one inner `FixedSizeList[3]` per vertex. |
| `color` | `List<FixedSizeList<Float32>[3]>` | optional | Per-vertex RGB; must match the `position` length. Absent → all white. |
| `index` | `List<UInt32>` | optional | Triangle-list indices into the vertices. Absent → the vertices are a non-indexed triangle list (count must be a multiple of 3). |

Validation (`Mesh::from_arrow_all`) rejects a missing/mistyped `position`, a
`color` whose length differs from `position`, an `index` out of range, a
non-indexed vertex count not divisible by 3, null values, and an empty table.

### Preview transform (scale-to-fit)

Each loaded mesh is rendered **centered and uniformly scaled to fit**: the core
applies a per-mesh `base_model = scale_to_fit · translate(-aabb.center())`, where
`scale_to_fit` is a **uniform** `s = target / max_extent(aabb)` (`target` ≈ 2
world units). It composes **beneath** the per-frame per-instance `model`, so the
effective transform for a drawn instance is:

```
clip = P · V · (model · base_model) · (position, 1)
```

An arbitrary-unit, off-origin asset (e.g. `assets/meshes/bunny.obj`) therefore
renders centered at the world origin at a reasonable size, while a per-frame
`model` (e.g. a rotation) still animates on top. The preview lives entirely in the
core (single source of truth); producers only send per-frame params.

## Params stream schema

Extends [0.0.2](./0.0.2.md) (`center`/`size`/`theta` + optional `model`) with
**optional per-frame camera and multi-mesh draw-list columns**. Every optional
matrix/vector column is **all-or-nothing** (non-null for all rows) and defaults to
the identity when absent — an **identity matrix is simply omitted** rather than
serialized.

### Camera (optional, per-frame)

A frame's camera can be authored in either of two mutually exclusive forms; mixing
them is an error.

**CV form** (computer-vision, pixel intrinsics + extrinsics):

| Column | Arrow type | Meaning |
|---|---|---|
| `k` | `FixedSizeList<Float32>[9]` | Column-major pinhole intrinsics `K` (`fx, fy, cx, cy`, skew). Wins over CG projection. |
| `pose` | `FixedSizeList<Float32>[16]` | Column-major camera-to-world matrix; the view matrix is its inverse. Wins over CG view. |

**CG form** (computer-graphics, look-at + perspective):

| Column | Arrow type | Meaning |
|---|---|---|
| `eye` | `FixedSizeList<Float32>[3]` | Camera position. |
| `target` | `FixedSizeList<Float32>[3]` | Look-at point (wins over `direction`). |
| `direction` | `FixedSizeList<Float32>[3]` | View direction (used when no `target`). |
| `up` | `FixedSizeList<Float32>[3]` | Up vector (defaults to `+Y`). |
| `fovy` | `Float32` | Vertical field of view (radians). |
| `aspect` | `Float32` | Aspect ratio (defaults to `width/height`). |
| `znear` | `Float32` | Near clip (defaults to `0.1`). |
| `zfar` | `Float32` | Far clip (defaults to `1000.0`). |

Resolution: CV wins per component (`pose` → view, `k` → projection); otherwise the
CG look-at/perspective is built; otherwise identity. An `eye` without a look
`target`/`direction` (or vice versa) is rejected as an incomplete CG camera.

### Multi-mesh draw list (optional, per-frame)

To place several instances of the stream's meshes in one frame:

| Column | Arrow type | Meaning |
|---|---|---|
| `draw_mesh` | `List<UInt32>` | Per-instance mesh index into the mesh table (0-based row). |
| `draw_model` | `List<FixedSizeList<Float32>[16]>` | Per-instance column-major `model` matrix, applied beneath that mesh's preview transform. |

Both columns must be present together and have equal per-row length (one mesh id
and one model per instance). A `draw_mesh` index outside the mesh table is
rejected. **When the draw list is absent, one instance of mesh 0 is placed by the
frame's own `model`** — preserving the single-object `0.0.2` behavior.

## Output schema

Unchanged from [0.0.1](./0.0.1.md) — four `fixed_shape_tensor<UInt8>` channels
`r, g, b, a` of shape `[height, width]`, one row per rendered frame.

## Example (input)

Encode an OBJ into the leading mesh stream, then concatenate the params stream:

```sh
# [mesh][params] on one stdin, rendered by trd-cli / trd-app
{ scripts/obj_to_arrow.py assets/meshes/bunny.obj;
  scripts/jsonl_to_arrow.py examples/frames.turntable.jsonl; } \
  | trd --width 256 --height 256
```

For a multi-mesh scene, pass several OBJs (one row each) and drive placement with
per-frame `draws`:

```sh
{ scripts/obj_to_arrow.py bunny.obj teapot.obj;   # mesh 0, mesh 1
  scripts/jsonl_to_arrow.py scene.jsonl; } | trd --width 256 --height 256
# scene.jsonl rows: {"draws": [{"mesh": 0, "model": [..16..]},
#                              {"mesh": 1, "model": [..16..]}], "fovy": 0.8, ...}
```

`examples/render.sh --mesh assets/meshes/bunny.obj examples/frames.turntable.jsonl
output/bunny.gif` wires the single-mesh case end-to-end.

## Changes from 0.0.2

See [`CHANGELOG.md`](./CHANGELOG.md). Summary: adds the optional leading **mesh**
Arrow stream (nested-list geometry, **all rows** decoded for multi-mesh scenes),
the multi-stream `[mesh][params]` framing, per-mesh scale-to-fit preview
transforms, optional per-frame **camera** columns (CV `k`/`pose` and CG
`eye`/`target`/`direction`/`up`/`fovy`/`aspect`/`znear`/`zfar`), and an optional
per-frame **draw list** (`draw_mesh`/`draw_model`) placing multiple mesh
instances. Params-only streams are unaffected.
