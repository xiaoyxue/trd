# Stream protocol 0.0.2

- **Version:** `0.0.2`
- **Status:** Current
- **Since:** this release
- **Compatibility:** backward-compatible with [0.0.1](./0.0.1.md) — 0.0.1 streams
  decode and render identically; decoders accept `{0.0.1, 0.0.2}`.

## Wire format

Apache Arrow IPC streaming format, `trd.protocol.version = "0.0.2"`.
**1 row = 1 frame**, output 1:1 with input (image schema unchanged from 0.0.1).

## Input schema

The 0.0.1 columns remain; 0.0.2 **adds three optional matrix columns**. A column
is validated only if present (**additive**), and every column is non-nullable
(including fixed-size-list children).

| Column | Arrow type | Required | Meaning |
|---|---|:--:|---|
| `center` | `FixedSizeList<Float32>[2]` | yes | 2D centroid (NDC), as 0.0.1. |
| `size` | `FixedSizeList<Float32>[2]` | yes | 2D per-axis scale, as 0.0.1. |
| `theta` | `Float32` | yes | Rotation (rad), as 0.0.1. |
| `model` | `FixedSizeList<Float32>[16]` | optional | Column-major 4×4 **model** matrix `M` (object → world). Supersedes `center`/`size`/`theta`. |
| `k` | `FixedSizeList<Float32>[9]` | optional | Column-major 3×3 **camera intrinsics** `K` (pinhole). Derives projection `P`. |
| `pose` | `FixedSizeList<Float32>[16]` | optional | Column-major 4×4 **camera pose** (world-from-camera). `V = pose⁻¹`. |

## Semantics & conventions

The vertex shader applies the full MVP chain:

```
clip = P · V · M · (position, 0, 1)
```

- **Matrices are column-major, right-handed; projection targets wgpu clip space
  (`z ∈ [0, 1]`).**
- **M (model):** the `model` column if present, else the synthesized 2D affine
  `translate(center) · rotate_z(theta) · scale(size)` (reproducing the 0.0.1
  formula `p' = center + R(theta) · (size ⊙ p_i)`).
- **V (view):** `inverse(pose)` if `pose` is present, else identity.
- **P (projection):** derived from `K` (`fx = k[0]`, `fy = k[4]`, `cx = k[6]`,
  `cy = k[7]`) and the render target's viewport, else identity. A centered
  principal point with square pixels reduces to a standard right-handed
  perspective; `near`/`far` are renderer constants until the camera slice (#18)
  makes them configurable.

**Defaults reproduce 0.0.1.** With no `model`/`k`/`pose` columns (or identity
values), `P = V = I` and `M` is the 2D affine, so the output is byte-for-byte the
0.0.1 result.

## Output schema

Unchanged from [0.0.1](./0.0.1.md) — four `fixed_shape_tensor<UInt8>` channels
`r, g, b, a` of shape `[height, width]` — but stamped
`trd.protocol.version = "0.0.2"`.

## Example (input)

Two frames rendered through an explicit model matrix (identity, then a scaled +
translated column-major 4×4), with no camera columns (identity `P`/`V`):

| center | size | theta | model (col-major 4×4) |
|---|---|---|---|
| `[0,0]` | `[1,1]` | `0` | *(absent → synthesized identity)* |
| `[0,0]` | `[1,1]` | `0` | `[0.5,0,0,0, 0,0.5,0,0, 0,0,1,0, 0.1,-0.2,0,1]` |

Authored as JSONL, one frame per line, each giving the `model` matrix directly
(see [`examples/frames.0.0.2.jsonl`](../../examples/frames.0.0.2.jsonl)):

```jsonl
{"model": [0.5,0,0,0, 0,0.5,0,0, 0,0,1,0, 0.1,-0.2,0,1]}
```

Feed it through the producer, which defaults to `--version 0.0.2`
(use `--version 0.0.1` for the `center`/`size`/`theta` form of
[`examples/frames.0.0.1.jsonl`](../../examples/frames.0.0.1.jsonl)):

```sh
scripts/jsonl_to_arrow.py examples/frames.0.0.2.jsonl   # → Arrow params stream
```

## Changes from 0.0.1

See [`CHANGELOG.md`](./CHANGELOG.md). Summary: adds the optional `model`, `k`, and
`pose` matrix columns and the full MVP transform; the 2D affine path is preserved.
