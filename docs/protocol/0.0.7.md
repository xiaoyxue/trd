# Scene protocol 0.0.7

- **Status:** current agreed contract (#367/#370).
- **Input:** `[params][mesh?]`, complete concatenated Arrow IPC streams.
- **Resources:** UUID plus original self-contained GLB bytes only.
- **Compatibility:** none with earlier wire formats.
- **Machine-readable contract:** [`0.0.7.schema.json`](0.0.7.schema.json).
- **Implementation caveat:** see the [atomic migration status](README.md#implementation-migration-status);
  current-contract documentation is not evidence that every producer/runtime
  already stamps this version.

## Input envelope

```text
[params]                    placement/reference geometry
[params] [mesh: one row]     one bound model
[params] [mesh: N rows]      multiple bound models
```

Each table has one schema and zero or more record batches. A supplied mesh
stream follows params and appears at most once. Resource batch boundaries are
not object identities and must survive roundtrip; resources are not repeated
per params row.

Versioned schemas carry:

| Key | Value |
|---|---|
| `trd.protocol.version` | exactly `0.0.7` |
| `trd.table.kind` | `params` or `mesh`, matching stream order |
| `trd.stream.frame_rate` | optional params playback rate; positive float, default 30 |

Wrong versions, wrong table order, duplicate streams, unknown extra tables and
malformed input are explicit errors. The upstream FHC adapter can read an
unversioned source table with its prescribed `bottom_quads`/`k` types; it does
not silently upgrade a table declaring an old trd version.

## Mesh table

Exactly two non-null fields, in this order:

| Field | Arrow type | Meaning |
|---|---|---|
| `mesh_id` | UUID extension over `FixedSizeBinary(16)` | unique resource identity |
| `glb` | `LargeBinary` | original bytes of a valid self-contained GLB 2.0 asset |

GLB owns geometry, textures and materials. No `position`, `index`, `color`,
`uv`, `normal`, `material`, `gltf_path` or `gltf_url` resource columns and no
separate texture stream are accepted.

Bindings resolve UUIDs to renderer-local slots. Resource row reordering must
not change UUID-bound objects, and export must not replace UUIDs with GPU
indices. Preserve GLB bytes even when the renderer does not consume every
embedded feature. External GLB buffers/images, malformed resources and unresolved
bindings fail explicitly; never substitute a cube for a failed model import.

Native/wasm callers may supply identified GLB bytes instead of a trailing
resource stream. Params-only input intentionally uses the built-in reference
cube, which is not serialized as a fake mesh asset.

## Tracked params adapter

Only the rendering subset is consumed; unrelated source fields remain retained.
The detailed source contract is [trd-render-sub-schema.md](../../assets/schemas/trd-render-sub-schema.md).

| Field | Arrow type | Requirement |
|---|---|---|
| `bottom_quads` | `List<FixedSizeList<Point,4>>` | one ordered quad per placement |
| `k` | FHC intrinsics struct | camera for the source image |
| `model` | `List<FixedSizeList<FixedSizeList<Float32,4>,4>>` | optional column; identity local model when absent |
| `mesh_id` | `List<UUID>` | per-instance asset bindings when required |
| `present_index` | `Int64` | optional source/video identity helper |
| `pts` | `Int64` | optional real timestamp helper, interpreted with its time base |
| `track_id` | `List<Utf8>` | optional stable instance identity for cross-frame edits |

`Point` contains non-null float32 `x,y,w,h`.
FHC `k` contains non-null float32 `fx,fy,cx,cy,skew,w,h`.
Geometry, matrix rows and list children preserve the source's required
non-null constraints. Per-placement lists align; coordinates/matrices are finite.

FHC is converted using the source image dimensions, not window dimensions:

```text
u = (x + w) / 2       v = (y + h) / 2
fx_px = fx / 2        fy_px = fy / 2
cx_px = (cx + w) / 2  cy_px = (cy + h) / 2
skew_px = skew / 2
```

Preserve source corner order and winding. Do not cyclically reorder, sort by
screen y, clamp off-image corners, or invent a different quad homography.
The first edge determines placement basis and scale.

**Tracked `model` is row-major on the wire.** The adapter converts it to the
internal column-major matrix; export writes the original nested row-major form.
Do not rename this column to `draw_model`.

## CG/CV params adapter

The existing non-FHC camera/draw vocabulary remains a separate adapter, including
golden fixture camera values and conventions:

| Field | Arrow type | Semantics |
|---|---|---|
| `model` | `FixedSizeList<Float32,16>` | column-major model for the implicit single draw |
| `k` | `FixedSizeList<Float32,9>` | column-major pixel intrinsics |
| `pose` | `FixedSizeList<Float32,16>` | column-major camera-to-world pose |
| `eye`, `target`, `direction`, `up` | `FixedSizeList<Float32,3>` | CG look-at camera; target takes precedence over direction |
| `fovy` | `Float32` | vertical radians |
| `aspect`, `znear`, `zfar` | `Float32` | preserve viewport/default projection behavior |
| `draw_mesh` | `List<UInt32>` | this adapter's ordered resource indices, not source UUID replacement |
| `draw_model` | `List<FixedSizeList<Float32,16>>` | column-major instance matrices |
| `draw_mode` | `List<UInt8>` | aligned optional per-draw render selection |
| `video_frame_index` | `UInt32` | retained sparse frame helper for this adapter |
| `frame_path`, `frame_url` | nullable `Utf8` | optional external still references |
| `tonemap` | `UInt8` | optional constant tone-map operator: 0 Reinhard, 1 ACES |

An eye requires a target/direction and vice versa. Do not mix CG and CV camera
forms. Missing camera halves retain identity behavior; do not invent a camera.
Defaults remain +Y up, near 0.1 and far 1000 for perspective.

Draw-mode bytes remain 0 filled, 1 wireframe, 2 textured, 3 blob shadow,
4 shaded/PBR and 255 inherit. The global render choice remains a caller option.
The old camera/draw vocabulary does **not** permit the old resource envelope.

## Placement and frame persistence

For quad-bound models:

```text
world_model = placement_for_this_frames_K_and_quad * saved_local_model * asset_base
```

`asset_base` fits the longest GLB extent to one quad half-edge unit and grounds
the AABB bottom center. It is derived identically on authoring/replay, not
accumulated into the saved matrix or GLB. There is no old preset offset/lift.
No-quad scenes retain their ordinary world-space model semantics.

Editor moves/rotations/scales update **all corresponding existing sparse rows**.
Each stores `adjustment * original_local_model`; repeated drag updates replace
the adjustment against captured baselines. Track IDs handle reordered or missing
instances. Without IDs, only a consistent ordered binding list establishes
correspondence; ambiguity is an error.

Round one edits, seeks, plays and exports. Round two freshly opens that export
with the same external video and reproduces saved matrices while seeking and
playing. Identity UI adjustment controls on replay must not apply edits twice.

## Lossless source retention

Retain complete schemas, unknown columns, original types/nulls, field/schema
metadata, row order and params/mesh record-batch boundaries. Modify only intended
model/binding entries; untouched matrices must not be decomposed into TRS.
Original GLB bytes remain byte-identical. IPC envelope bytes may change after
editing, but unrelated Arrow data must not.

## External media and output

Video remains an independent decoder/player source. Source frame identity/real
PTS selects sparse rows; missing rows are video-only. Never create model rows
for an untracked tail or manufacture packet PTS from a nominal fps grid.

External stills are optional CG/CV references resolved by the delivery surface.
`frame_id`, inline-frame streams and Arrow texture tables are retired inputs.

The CLI outputs one row per params row: planar `r,g,b,a` fields containing
`fixed_shape_tensor<UInt8>[height,width]`, with params batch boundaries and
standalone playback-rate metadata preserved.

## Migration from 0.0.6

Change readers, producers, fixtures, generated schemas and version stamps
atomically. Reorder to params-first, use original GLB resources (or explicit
offline OBJ-to-GLB conversion), externalize inline image resources, and retain
camera/draw values. Merely changing the version string on old resource tables
does not create a valid 0.0.7 document.

Old annotation 0.2.0 data is offline source, not an editor mode. Convert it
explicitly with `scripts/timeline_to_params.py`. Ordinary internal OBJ viewers
and their rendering support are unaffected.
