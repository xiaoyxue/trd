# Mesh assets

Sample meshes used to exercise trd's data-driven mesh rendering (see #19 and its
breakdown, e.g. the OBJ loader in #36).

| File | Description | Source |
|---|---|---|
| `bunny.obj` | Stanford Bunny (~34.8k vertices, ~69.6k triangles, with normals). Wavefront OBJ. | [xiaoyxue/Gyunity `resources/meshs/bunny3.obj`](https://github.com/xiaoyxue/Gyunity/blob/master/resources/meshs/bunny3.obj) |

The Stanford Bunny is a classic scanned model from the Stanford 3D Scanning
Repository, widely redistributed for graphics research and testing.
