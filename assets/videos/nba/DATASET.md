# NBA broadcast camera K / VP / cube dataset (shots 2 & 7)

Per-frame camera calibration + AR-cube geometry extracted from an NBA broadcast clip whose
main camera is **rotation + zoom only** (a static-scene inter-frame homography tracks every
static 3D point). Produced by the K-estimation research tracked in issue
`Hong-Xiang/VideoAnalysis#1133`.

Contact / provenance: generated by @Hong-Xiang (Copilot CLI session). Source scratch tree:
`~xianghong/data/case-nba/work/floor_cal/`.

## Primary dataset schema (`per_frame_KVP_cube.parquet`)

**Grain:** one row per `(shot, method, present_index)`.
**Coordinates:** all image quantities are in **source-video pixels** (origin top-left).

| column | type | meaning |
|---|---|---|
| `shot` | int | NBA shot id (2 or 7) |
| `method` | str | K-estimation algorithm — see "Methods" below |
| `present_index` | int | global video frame index |
| `f_ref_px` | float | the method's calibrated focal (pixels); **the value used in `K`** |
| `f_frame_px` | float | == `f_ref_px` (kept for schema stability) |
| `f_frame_raw` | float | EXPERIMENTAL per-frame focal from `center(H_i)*K_ref`; mostly unobservable here — use only where `f_frame_reliable` |
| `f_frame_reliable` | bool | per-frame focal self-consistent + rotation observable (rare on this footage) |
| `tilt_deg` | float | floor-normal tilt for this method (const per shot+method) |
| `cx, cy, W, H` | float/int | principal point (frame center) + frame size |
| `K` | float[9] | 3x3 **row-major** intrinsics: `[f,0,cx, 0,f,cy, 0,0,1]` |
| `vp_len` | float[3] | cube **X-axis** VP = court-length dir `r1`, homogeneous `[x,y,w]` **this frame** |
| `vp_wid` | float[3] | cube **Y-axis** VP = court-width dir `r2`, homogeneous |
| `vp_up`  | float[3] | cube **Z-axis** VP = floor normal `r3`, homogeneous (`w~0` => at infinity) |
| `has_ad_quad` | bool | `ad_quad` is tracked (True) or H-propagated from ref (False) |
| `ad_quad` | float[8] | 4 ad-unit corners `(x,y)` in order **UL, UR, LR, LL** |
| `cube_verts` | float[16] | 8 cube vertices `(x,y)` order `[b0,b1,b2,b3, t0,t1,t2,t3]` |
| `h_ref_to_i` | float[9] | 3x3 row-major homography ref-frame -> this frame |

### Vertex & VP conventions
- `cube_verts` bottom `b0..b3` = the ad-unit quad ring (UL,UR,LR,LL); `t_k` is `b_k` extruded
  along the floor normal (up). **Edges:** bottom ring `0-1-2-3-0`, top ring `4-5-6-7-4`,
  verticals `0-4,1-5,2-6,3-7`.
- VPs are stored **un-normalized homogeneous** so at-infinity vanishing points are preserved.
  To get a finite image point: `x,y = vp[:2]/vp[2]` (only when `abs(vp[2])` is not ~0).
  On this footage `vp_len` (sidelines) is essentially at infinity (`w/|xy| ~ 1e-5`).

## Methods (the `method` column)

| method | shot | focal px | trust |
|---|---|---|---|
| `BA_2511` | 2 | 2511 | **reliable** — motion self-calibration (RAFT correspondences over frames) |
| `BA_2568` | 7 | 2568 | **reliable** — same |
| `Zhang_3533` | 2 | 3533 | experimental — known-rectangle (NBA paint 5.791x4.877 m); shot-2 paint is edge-on, noisy |
| `Zhang_2538` | 7 | 2538 | **good** — ~1.2% from BA (shot-7 paint well-conditioned) |
| `2VP_6127` | 2 | 6127 | **degenerate** — sidelines VP at infinity => focal unconstrained; unusable |
| `2VP_9160` | 7 | 9160 | **degenerate** — same |
| `1circle_4224` | 2 | 4224 | experimental — single-circle IAC (floor circle) |
| `3circle_3643` | 2 | 3643 | experimental — 3-circle joint (weak horizon) |

**Recommendation:** use `BA_*` as the trustworthy K; `Zhang_2538` (shot 7) corroborates it.
Treat `2VP_*` as degenerate and the circle methods as experimental.

---

## Important caveats (read before using)

1. **K is per-method constant across frames (the calibrated focal).** The camera does zoom, but
   the per-frame *zoom* is **not reliably observable** from the tracked homographies on this
   low-rotation footage. The genuine per-frame variation is carried by `vp_*`, `cube_verts`,
   `ad_quad`, and `h_ref_to_i` (all vary via H). If you need a zoom curve, recompute with
   correspondence-based per-frame focal (RAFT) — not included here.
2. **Coverage = shots 2 & 7 only** (the shots with real court VPs). The other 8 shots have a
   reliable BA focal in `ba_focals.parquet` but no court VPs => no 3-VP / cube.
3. **VP semantics differ by whether the VP is finite.** Always guard the homogeneous divide.

## Loading

```python
import pandas as pd, numpy as np
df = pd.read_parquet("per_frame_KVP_cube.parquet")
row = df[(df.shot == 2) & (df.method == "BA_2511") & (df.present_index == 503)].iloc[0]
K     = np.array(row.K).reshape(3, 3)
verts = np.array(row.cube_verts).reshape(8, 2)   # [b0..b3, t0..t3]
adq   = np.array(row.ad_quad).reshape(4, 2)       # UL,UR,LR,LL
vp_up = np.array(row.vp_up)                        # homogeneous [x,y,w]
H     = np.array(row.h_ref_to_i).reshape(3, 3)
```

To overlay on the actual video, use the bundled `NBA.mp4`: `present_index` is the **0-based
frame index** into it (e.g. shot 2 = frames 428..579 ~ 14.3-19.3 s; shot 7 = 1440..1638 ~
48.0-54.6 s at 30 fps). Grab a frame with OpenCV/PyAV:

```python
import cv2
cap = cv2.VideoCapture("NBA.mp4")
cap.set(cv2.CAP_PROP_POS_FRAMES, int(row.present_index))
ok, bgr = cap.read()   # bgr matches the dataset's pixel coordinates
```

The `rrd/` files also embed the frames for quick visual inspection.
